# Vesper for JetBrains Fleet / Air

A [Fleet](https://www.jetbrains.com/fleet/)-format port of the Vesper theme, for
**JetBrains Fleet** and **Air**. These editors are built on the Fleet engine —
not the classic IntelliJ Platform — so they cannot load the IntelliJ theme
plugin in the root of this repo. This is the same palette rebuilt in Fleet's
native theme format.

## Install

Copy `Vesper.json` into your themes folder:

| Editor        | Themes folder                                             |
| ------------- | -------------------------------------------------------- |
| Fleet         | `~/.fleet/themes/`                                        |
| Air (macOS)   | `~/Library/Application Support/JetBrains/Air/themes/`     |

Then select **Vesper** from **⌘⇧K → "Theme"** (or Settings → Appearance → Theme).

## Palette

`#101010` background · `#FFFFFF` text · `#A0A0A0` muted · `#FFC799` orange ·
`#99FFE4` mint · `#FF8080` red.
